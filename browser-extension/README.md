# json4matter — 浏览器扩展版

把桌面版 [json4matter](../README.md)（WPF + .NET 8）的 JSON 格式化查看能力搬到浏览器里，
**专治「接口日志里那坨被序列化的 JSON 字符串」**：复制出来贴进去，自动剥掉转义、树形着色、一眼看清结构。

> 适用场景：平台/网关的接口日志查询页把 JSON 以字符串形式展示（如 `"{\"code\":200,\"data\":{...}}"`），
> 肉眼几乎没法读。用本扩展**选中日志里的那段字符串 → 右键「用 json4matter 格式化选中内容」**，
> 或直接复制粘贴到扩展里，即可得到格式化后的树。

## 安装（Chrome / Edge，免打包）

1. 打开扩展管理页：`chrome://extensions`（Edge 为 `edge://extensions`）
2. 打开右上角「**开发者模式**」
3. 点「**加载已解压的扩展程序**」，选择本目录 `browser-extension/`
4. 工具栏出现薄荷绿 `{}` 图标即安装成功

## 两种打开方式

- **点图标 → 弹窗**：随手看一下，关掉即走。
- **右键图标 → 「在边栏中打开」 / 或页面右键菜单「打开 json4matter 侧边栏」**：占满屏幕高度、可拖动调宽，适合长时间对照阅读大 JSON。

两种视图是同一个页面，主题、字号、输入内容都会保留。

## 功能（对齐桌面版）

| 功能 | 说明 |
|---|---|
| **转义 JSON 自动解包** | 整段是 `"{\"code\":200,...}"` 这类被序列化的字符串时，自动逐层剥开（最多 5 层），状态栏提示「已解包 N 层转义字符串」。也兼容**没有外层引号**的转义形式 `{\"code\":200}` |
| 内嵌转义值展开 | 某个字段的值本身是 JSON 字符串时，值行仍显示转义原文，同时生成可展开、可搜索的结构化子树 |
| 粘贴即解析 | 左侧源码 280ms 防抖自动解析，状态栏显示节点数与耗时 |
| 左右双栏 | 左源码、右格式化树；对象默认展开，数组默认折叠 |
| 数组折叠标数 | 数组显示 `[N]` 数量徽标 |
| 类型着色 | 字符串 / 数字 / 布尔 / null 分色；key 近黑，数组下标灰蓝 |
| 单击子树高亮 | 点任意节点，整棵子树浅色高亮，状态栏显示路径 `a › b › c` |
| 展开 / 折叠全部 | 一键铺开或收拢 |
| 搜索 | 键搜索 / 值搜索，命中黄色高亮 + 计数，自动展开命中祖先并滚动定位；Enter 重搜、Esc 清除 |
| 复制 | 复制格式化后的 JSON（保真：数字精度、字符串原文不重排） |
| 压缩 | 「压缩」中文转 `\uXXXX`；「压缩原文」保留中文 |
| 隐藏空值 | 过滤 null、空字符串、空数组、空对象 |
| 三主题 | 清新绿 / 纸质黄 / 清爽白，实时切换并记忆 |
| 字号 | 11–20 无级调节，记忆 |
| 容错解析 | 容忍 `//`、`/* */` 注释与尾随逗号 |

## 快捷键 / 交互

- 源码框输入即解析；`Enter` 在搜索框重复搜索，`Esc` 清除搜索高亮
- 树节点：单击选中并高亮子树；点 `▸` 或双击展开/折叠

## 与桌面版的差异

- 未包含「修改标红（Diff）」：桌面版依赖对照首次格式化的基线，浏览器版定位为**只读查看/格式化**，输入区改动即整体重新解析。
- 未包含多媒体（图片/PDF/视频）预览。
- 解析器的数字/字符串保留原始文本，序列化保真。

## 目录结构

```
browser-extension/
├── manifest.json        # MV3 清单
├── index.html           # 弹窗 / 侧边栏共用的同一页面
├── css/styles.css       # 三套主题（Token 化，来自 Themes/*.xaml）
├── js/parser.js         # 容错解析 + 转义解包（纯前端，无依赖）
├── js/app.js            # 界面与交互
├── js/background.js     # service worker：右键菜单 + 打开侧边栏
├── icons/               # 图标（gen_icons.py 可重新生成）
└── tests/               # 回归测试（Node + jsdom）
```

## 开发与测试

纯静态、零构建。改完在扩展管理页点「刷新」即可。

```bash
# 解析器单元测试（12 项）
node tests/_test_parser.js

# UI 冒烟测试（21 项，需 jsdom）
npm install jsdom          # 或全局可用
NODE_PATH=./node_modules node tests/_test_ui.js
```

也可以直接用浏览器打开 `index.html` 预览界面（此时设置退回到 localStorage）。
